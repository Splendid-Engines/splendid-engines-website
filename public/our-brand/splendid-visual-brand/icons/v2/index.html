Splendid Engines Icons
v2 · Lucide-Sourced

Fifty-eight icons covering Splendid's domain vocabulary plus the generic UI primitives the product, the website, and decks need. Sourced from Lucide (ISC license, ~1,500 icons), coerced to the Splendid spec: 2.5px stroke, square caps, miter joins. Three color variants pre-baked: Lagoon for light surfaces, Poppy for methodology accents, white for dark surfaces.

v2.0 · Built from lucide-static@0.469.0. Run npm run icons:build from the repo root to regenerate. Concept-to-icon mapping at concept-map.csv.

Usage

Website (static HTML)

Reference the pre-baked SVG file directly via img tag, or inline the SVG and apply the .splendid-icon utility class for color cascade. For methodology accents, use the Poppy variant.

<img src="/our-brand/splendid-visual-brand/icons/v2/lagoon/signal.svg" width="24" height="24" alt="">

Product app (Next.js)

Use the Icon wrapper at src/components/Icon.tsx with a Lucide React component. Wrapper applies brand defaults (2.5 stroke, square caps, miter joins, Lagoon stroke).

import { Icon } from '@/components/Icon';
import { Signal } from 'lucide-react';

<Icon as={Signal} tone="lagoon" size={24} />

Decks (Google Slides)

Download the spec-coerced SVG in the color you need (Lagoon, Poppy, or white) from this directory. In Slides, use Insert > Image > Upload from computer. Never paste raster PNG.
